Formulas

Start with = in a cell or the formula bar. Use cell references like A1, ranges like A1:A5, and arithmetic like =(B2-C2)*10%.

=SUM(A1:A5)
Adds the numbers in the range.
=AVERAGE(A1:A5)
Finds the mean of the numbers.
=MIN(A1:A5)
Finds the smallest number.
=MAX(A1:A5)
Finds the largest number.
=COUNT(A1:A5)
Counts cells that contain numbers.

Working with sheets

  • Edit and navigate. Select a cell and type to replace it. Double-click or press F2 to edit its current value. Use the arrow keys to move or enter a cell address to jump there.
  • Select a range. Drag across cells, hold Shift while clicking or using the arrow keys, or enter an address like A1:B5. Copy, clear, or format the whole selection at once.
  • Analyze data. Open Statistics, choose an analysis, then type a range or use your selection.
  • Format and undo. Apply text styles, number formats, cell fills, or borders from the toolbar. Use Undo or Redo to step through changes.
  • Manage sheets. Click + to add a sheet. Double-click a tab to rename it.
  • Generate test data. Open Test data, set a destination range, and choose a distribution.
  • Save, export, and print. Changes save in this browser. Use File to save or open a workbook copy, export values to CSV, or print the active sheet.
