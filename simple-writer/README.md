# Simple Writer

A lightweight, standalone word processor that works in a modern web browser.

## Run

Open [Simple Writer](./index.html) locally, or visit the GitHub Pages deployment:

https://bluehattom.github.io/Apps/simple-writer/

## Features

- Bold, italic, underline, strikethrough, font size, text and highlight color
- Headings, lists, text alignment, hyperlinks, undo/redo
- Print and save to PDF with the browser's print dialog
- Save HTML, open HTML or text files
- Browser-local autosave, document name, and word count

## Notes

No build tools, backend, account, or external libraries are required. Local autosave is specific to the browser and origin. For a durable copy, export your document as HTML.
