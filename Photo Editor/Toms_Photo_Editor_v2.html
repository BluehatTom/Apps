Using Tom's Photo Editor

1. Add your image. Choose Open image or drag a photo into the workspace.

2. Make edits. Use the left tool menu. Drag the corners to crop, adjust sliders, or add text and brush strokes. To move text, select the Text tool and drag it on the photo.

3. Remove backgrounds. Select Remove BG for one-click AI subject isolation (internet needed to load the model) or use the offline color wand and cleanup brush. Export PNG to keep transparency.

4. Batch process. Select Batch, add photos, set output options, then choose Process photos and Download ZIP.

5. Save your result. Select Export for PNG, JPEG, or WebP.
