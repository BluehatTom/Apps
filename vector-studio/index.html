A little studio. A lot of possibilities.

Draw with rectangle, ellipse, line, pencil, polygon pen, star, or text. Drag on the artboard to create shapes. Click with Text to place your words.

Pen: click to add points; Enter finishes an open path, or click the first point to close it. Escape cancels.

Edit: select an object and drag to move. Drag corner handles to resize, or the top circular handle to rotate. Shift-click for multiple selection. The node tool edits pen, pencil, and line points.

Fractals: choose a pattern, tune the live preview, then add it to your artboard. The result is vector artwork.

Shortcuts: V select · N nodes · R rectangle · E ellipse · P pen · B pencil · L line · S star · T text · Delete remove · Ctrl/Cmd+D duplicate · Ctrl/Cmd+Z undo · Shift+Ctrl/Cmd+Z redo · Ctrl/Cmd+S save project · Space+drag pan.

Projects autosave in this browser. Save a project file to keep a backup or move it to another computer. Open accepts project JSON and sanitized SVG artwork. Imported SVGs are editable as a whole object.
